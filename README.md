A program that writes one roast line to `/output/entry.txt` (122 characters, inside the 1–200 character gate): "The egg tray in my fridge door has held the same six eggs since March, and they have now outlived two of my relationships." The setup is the same six eggs sitting in the door tray since March; the twist lands in the last few words — they outlived two relationships. A specific, recognisable detail (the egg tray) nobody else roasts, and it reads cleanly aloud in one breath.

## Run it

```sh
python3 main.py
```
